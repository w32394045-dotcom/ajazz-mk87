# MK87 统一真机测试计划（静态逆向已完成，全部真机项在此）

> ✅ **本计划已执行完毕（2026-11-01）**：逐项结果见 [TEST-REPORT.md](TEST-REPORT.md)。


> 前提：静态逆向全部收口（见 [FEATURES.md](FEATURES.md)）。本计划只做真机验证，按"低风险 → 高风险"排序。
> 工具：`probe/ajazz.py`（原生 HID 客户端）+ 各参考实现脚本；官方网页驱动作为**恢复手段**备用。

## 0. 测试前准备（Phase 0）

1. **备份现状**：`ajazz.py dump` 保存为 `docs/device_dump_pre_test.json`；记录 `GET_DEVICE_INFO` / `GET_GAME_MODE` / `GET_LED_EFFECT` / `GET_KEY` / `GET_FN_KEY` / `GET_CUSTOM_LED_DATA` / `GET_MACRO` 全量原始值。
2. **屏幕告知**：当前壁纸**无法读取备份**（协议只写不读）。测试开始前请用户确认：可以接受屏幕内容被测试图覆盖；恢复方式 = 用官方网页驱动 TFT 页重新保存图片/动画，或我们工具推回。
3. **恢复手段就绪**：官方驱动/网页驱动可用；`ajazz.py` 的 `SET_KEY` 整表回写、`SET_LED_EFFECT`、`SET_GAME_MODE` 原样回写均已验证可恢复。
4. **断开风险**：写操作单条执行、逐条回读确认；出现异常先停止，不连续重试。

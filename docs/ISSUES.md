## 1. 键盘 Win/Mac 模式（按键错位最常见原因）

- MK87 背面有一个 **Win/Mac 拨动开关**。Mac 档时固件把 **Win / Alt 互换**，OS 侧看到的是
  「按物理 Win 键 → `VK 0x12`（Alt）」；Windows 档才是「按物理 Win 键 → `VK 0x5B`（Win）」。
- 拨动开关时键盘会 **USB 重新枚举**（短暂断连属正常；若正在播放音乐律动，会中断后自动恢复）。
- 升级到 v0.1.8.6 后：**按键测试 → 键盘模式检测** → 点「开始检测」→ 按一下键盘上印着 Win（⊞）的键
  （10 秒内有效）→ 立即显示「Windows 模式」或「Mac 模式（Win/Alt 互换）」。
- 若显示 Mac 模式：改键页顶部会出现红色横幅提醒；把背面开关拨回 Windows，等键盘重新连接后重新检测即可。
  **此模式下改键仍然有效，只是按键位置与预期不同。**

## 2. 切 Win/Mac 模式后音乐律动不更新

- 旧版现象：键盘重连了，但音乐帧不再下发、界面仍显示「律动中」、电平条冻结。
- 现在：键盘掉线时徽章显示「等待键盘」，重连后自动续播（目标 ≤5 秒）、参数不丢；
  只有用户点「停止」才真正结束。
- 若仍出现：先到「设备信息」页确认键盘已重新连上，再导出日志反馈（见第 6 节）。

## 3. 按键测试崩溃 / 托盘图标消失

- 根因：按键扫描的 Windows 窗口过程回调对象被回收（访问违例），进程崩溃后托盘图标随之消失；
  已通过强引用回调对象、成对注销窗口类、修正 Raw Input 缓冲区语义修复。
- 开发构建实测：修复前 8 次 start/stop 出现 24 条访问违例；修复后连续 50 次 0 崩溃、
  GDI / USER 句柄数不变。
- 建议升级后自己再连续开关 50 次确认（日志里不再出现 `access violation` 即可）。

## 4. Windows 托盘图标消失、窗口找不回

- 旧版：「有图标对象」不等于「图标真的显示在通知区域」。图标实际未注册时点 X，窗口被隐藏而图标不存在，
  应用就彻底找不回了。
- 现在：程序会定期检查图标是否真的在；Explorer 重启或图标丢失会**自动重加 / 重建**；托盘确实不可用时，
  点 X 只**最小化到任务栏**并提示原因，不会再「隐身」；首次隐藏会提示图标可能被收进
  「显示隐藏的图标」（任务栏溢出区）。
- 重复启动 v0.1.8.6 时，若已有实例会尝试唤起它的窗口；唤起失败会弹窗说明，而不是静默变成第二个实例。

## 5. Linux 一键安装 AppIndicator 扩展

- 入口：**设置 → 系统托盘**（GNOME 缺扩展时卡片自动置顶）。
- 步骤：点「一键安装 AppIndicator 扩展（一次管理员密码）」→ `pkexec` 弹出系统密码框（只输一次）→
  自动安装并启用 → Wayland **注销重新登录**（X11 可 `Alt+F2` → `r`）→ 托盘图标出现。
- 扩展已安装但未启用时，按钮为「启用扩展（无需管理员密码）」。
- 没有 `pkexec` / 没有 polkit 认证代理时，界面不会盲目跑 `sudo`，而是给出可复制的手动命令。
- 浏览器模式（`python run.py`）没有提权入口，只显示复制命令；一键安装仅在 `.deb` / `.rpm` 桌面版可用。
- **状态：仅单测通过（87/87），未在真实 Linux 桌面实测**，欢迎按上面步骤验收。

## 6. 升级提醒（重要）

1. 安装 v0.1.8.6 前先**退出正在运行的旧版本**（当前机器装着 v0.1.8.4，且可能还有 dev 0.1.8.2 实例），
   避免旧实例占着 USB 句柄。
2. 直接覆盖安装即可：Windows 安装版运行新 setup / 便携版解压覆盖；Linux
   `sudo apt install ./mk87_*.deb` / `sudo dnf install ./mk87-*.rpm`。**无需重装驱动。**
3. 若新版本识别不到键盘：拔插一次键盘 USB 线，或重启程序。

## 7. 还有问题怎么反馈

- 应用内：**设置 → 日志与诊断 → 一键导出诊断包**；
- 日志位置：Windows `%LOCALAPPDATA%\mk87\logs`（`crash.log` 记录 Python 崩溃栈）；
  Linux `~/.local/state/mk87/logs`；
- 附上操作时间（尽量精确到分）、键盘连接方式（USB / 2.4G）与现象截图，便于对照日志时间线。
